# Text recognition models and data: provenance

## PaddlePaddle PP-OCRv5 mobile (Apache-2.0)

The models listed in `runtime/ocr/model-catalog-v1.json` are unmodified ONNX exports published by PaddlePaddle on Hugging Face, used under the Apache License 2.0 (`third_party_licenses/Apache-2.0.txt`). Every download URL is pinned to an immutable repository commit, and a file is used only when its byte size and SHA-256 match the catalog.

The recognizer dictionaries in `runtime/ocr/dictionaries/` are the unmodified `inference.yml` files of the same commits and ship inside the app. The model weights are never bundled.

## Unicode CLDR (Unicode-3.0)

`coverage/cldr-exemplars.json` holds CLDR main exemplar character sets and English language names, generated by `scripts/ocr/cldr-exemplars.py` from the pinned `unicode-org/cldr-json` release. It is used only by tests, under the Unicode License v3 (`third_party_licenses/Unicode-3.0.txt`).
