## What's new in 5.1.4
ReFra 5.1.4 gives you more control over modified-date sorting while making cloud cleanup, maps, editing, search, navigation, and native compatibility more reliable.

### New features
- **Optional modified-date updates** — Choose whether copying, renaming, editing, or rotating media updates its modified date and moves it to the top of modified-date views.

### Improvements
- **Android 16 KB compatibility** — Native libraries and JPEG 2000 support now meet current 64-bit Android alignment requirements.
- **Easier Obtainium installation** — The project download options now include a one-click Obtainium entry point.

### Bug fixes
- **Safer cloud storage cleanup** — Free Up Space verifies exact backups on every configured destination, preserves your options, and rechecks each deletion batch.
- **Complete, resilient cloud sync** — Manual refresh processes every page, while SMB and NFS recover after network or VPN changes.
- **Reliable cloud account removal** — Server removal finishes before leaving settings, with progress feedback and a retry option if it fails.
- **Reliable maps and locations** — Map previews recover more gracefully, location names are repaired, and nearby places remain distinct.
- **Reliable editing and markup** — Editor previews, markup tools, undo state, and full-resolution saves remain consistent.
- **Correct search and Smart Features results** — Date results are newest-first, and category classification data persists correctly.
- **Smoother media navigation** — Predictive back, external viewer reuse, and timeline scrubbing behave more reliably.
- **Layout and accessibility polish** — Filter chips retain a generous touch target, and Albums respects side-navigation insets.
