## What's new in 5.2.1
ReFra 5.2.1 lets Free Up Space run itself on a schedule per cloud account, adds visual search and file renaming to the media viewer, brings monochrome launcher icons, a single lock for every vault, and a large round of fixes across the viewer, cloud providers, categories and locations.

### New features
- **Scheduled Free Up Space** — run cleanup automatically every day, 3 days or week per cloud account; posts a notification with the removed count or a review prompt.
- **Visual search** — send the viewed image or current video frame to a provider like Google Lens, straight from the media viewer.
- **Rename in the viewer** — rename files from the quick bottom bar; the edit action gets a distinct sliders icon.
- **Monochrome launcher icons** — ReFra Monochrome and Gallery Mono join the logo picker.
- **Exclude videos from categories** — only photos are matched, with an option to purge existing video entries.
- **One lock for all vaults** — let the vault-selector gate stand in for per-vault passwords.
- **Dark viewer background** — keep the viewer black even under light theme.
- **Hide the locations section** — turn the Library locations row off in Timeline & Albums settings.
- **Auto-open keyboard on search** — the keyboard appears as you enter search, with a switch to disable it.

### Improvements
- **Top scrim everywhere** — the floating search bar keeps a readable backdrop on every grid screen.
- **Honest ignored-album patterns** — path regex matching with verified examples and a live match count.

### Bug fixes
- SMB/NFS sessions rebuild on network changes and dead-link reads.
- The vault picker no longer reveals vault names while the gate is locked.
- Viewer: no dismissal during partial loads, correct exit navigation, smoother return flights and restored double-tap-drag zoom.
- Rotate chip applies to the right file after swiping; wide-tile thumbnails are sharp again.
- Screen stays awake during video playback.
- Locations drop the bogus "Unknown Location" group.
- Markup text stays inside the canvas; crop clamps to image bounds.
- Vaulted media excluded from category counts; scan status stays in sync.
- Daily grouping restored with system date formats.
- Person merge crash and deleted AI models reinstalling fixed.
- No bogus error after a successful album move; splash icon on every launch.
