Ignoring removes albums from view without deleting, moving, or encrypting anything. Each entry under **Library › Ignored** is a rule with two decisions: **what** it matches (one album, several albums, or a path pattern) and **where** it hides them. Files stay where they are, so other apps and cloud backups still see them; use the [vault](/ReFra/features/vault) to lock photos away instead.

## Create a rule

1. Open **Library › Ignored** and tap **Ignore albums**. The same steps open when you touch and hold an album and choose **Add to ignored albums**.
2. Under **Choose what to ignore**, pick **Albums** or **Path pattern**.
3. For **Albums**, tick one or more albums; **Search albums** filters the list, and albums another rule already covers are marked **Already ignored**. For **Path pattern**, type the pattern (see below) and check the **Matches** list.
4. Under **Where should they be hidden?**, pick what to **Hide from**:
   - **Albums tab**: the album leaves Library; its photos stay in the Timeline.
   - **Timeline**: its photos leave the Timeline; the album stays in Library.
   - **Everywhere**: hidden from both.
5. Optionally give the rule a name, then confirm.

## Path patterns

A path pattern is matched against the **whole folder path**, not the album's display name. A photo in `/storage/emulated/0/DCIM/Camera` only matches a pattern that covers that whole string, so use `.*` where anything may appear.

The app offers these examples; tap one to start from it:

| Pattern | Matches |
| --- | --- |
| `.*Screenshots.*` | Anything with "Screenshots" in its path |
| `.*/WhatsApp/.*` | Everything inside the WhatsApp folder |
| `/storage/emulated/0/DCIM/.*` | Everything under DCIM on internal storage |

A pattern that does not parse shows **Invalid pattern**, and one another rule already uses is refused. When nothing matches yet the rule can still be saved: matching folders created later are hidden too. Check the **Matches** list before confirming; a broad pattern hides more than you meant.

## Manage existing rules

<PreviewCollection feature="ignored-albums" section="manage-existing-rules" />

**Library › Ignored** lists the rules grouped by where they hide albums, with filters for **All**, **Single album**, **Several albums**, and **Patterns**. Tap a rule to see its name, what it is **Hidden from**, and its albums or pattern, and to change them. **Stop ignoring** removes the rule; **Undo** on the confirmation brings it straight back.

Removing a rule makes its albums visible again where it had hidden them; nothing about the files changes in either direction.

## Example: hide messaging clutter only from the Timeline

1. Open **Library › Ignored** and tap **Ignore albums**.
2. Choose **Path pattern**, tap the WhatsApp example, and check the **Matches** list shows the folders you expect.
3. Hide from **Timeline** so the album stays in Library, and confirm.
4. WhatsApp media leaves the Timeline, but the files and the album remain.

## If the wrong things disappear

- Open **Library › Ignored** and check the albums a rule matches; path patterns match more than one folder when they are broad.
- A rule that hides from **Timeline** only is the reason an album still shows in Library; that is by design, not a leak.
- Ignored media may still feed search and smart features if **Include ignored albums** is on under **Settings › Smart Features**.
