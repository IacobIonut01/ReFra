**Media Info** in the viewer opens the details panel for the item on screen. At the top is the picture itself; below it, the fields the file carries.

## What the panel shows

<PreviewCollection feature="metadata" section="what-the-panel-shows" />

- **Label** (the display name), **Path**, **Taken on**, **Dimensions**, **Size**, and for videos **Duration**, **Frame rate**, and **Video format**.
- Print-oriented fields like **PPI**/**PPCM** appear when the file stores them.
- State badges mark items that are **Encrypted** or **Cloud**.
- **View all metadata** opens the complete field list the file contains.

## Editing

<PreviewCollection feature="metadata" section="editing" />

- Tap the **Label** field to open the **Edit Metadata** sheet, which edits the file's **Label** and **Description**; the pencil action in the viewer renames the file directly. A description on a video is stored in the app's database only; it is not written into the file.
- The **capture date** row lets you change **Date** and **Time** and then **Save Date**; the item moves in the timeline only when the timeline is ordered by capture time. Where the file format cannot carry a written date, the app instead offers **Create a dated copy**: a PNG copy carrying the new date, since PNG flattens animation, HDR, layers, and RAW data. The original is kept, and you then choose **Keep both** or **Move original to Trash**.
- To re-read metadata after a file changed outside the app, use **Refresh Metadata** under **Settings › Smart Features › Smart Features data**; see [Smart Features data](/ReFra/features/smart-scan).

## Location

- A photo or video without embedded GPS data shows no location at all; the row only exists where coordinates exist.
- With [media location permission](/ReFra/features/permissions) granted, a **Location** row shows where the photo was taken; tapping it opens a detail sheet with **Show in app** and **Open externally** (needs a map app installed).
- Without that permission the row offers **Grant access to read photo locations**. Denied permission only limits reading the device's embedded location data; a cloud item whose location the server already shared can still display it.

## Links to other tools

- A **backed up** row appears on items that exist on a cloud account; tapping it shows which providers hold the backup and offers deletion from a provider; covered under [cloud backup](/ReFra/features/cloud-backup).
- Category and people chips link into the matching groups; **Remove from person** on a face chip takes the photo out of that person group. See [people](/ReFra/features/people).
- **Remove metadata** starts the privacy-removal flow documented in [metadata privacy](/ReFra/features/metadata-privacy).

## Example: fix a scanned photo's date

1. Open the scanned photo, tap **Media Info**, open its capture date, set **Date** and **Time**, and tap **Save date**.
2. If ReFra offers **Create a dated copy**, tap **Create copy** and then **Keep both**.
3. Back in the gallery, open the new PNG copy and check its date in **Media Info**. With **Capture time** selected for the timeline order, it appears under the chosen date.
4. If you no longer need the original, select it separately and use the normal delete action after checking whether Trash is available. Keeping both avoids deleting anything during the date change.
