The ReFra editor never changes the file you opened. Every save writes a new copy, and the original stays where it was.

## The save menu

**Save** in the header opens the save menu:

- **Save copy** writes the copy in the format chosen under **Copy format** in the editor's settings.
- **Export as JPEG**, **PNG**, **WebP**, **HEIF**, or **JPEG XL** writes the copy in that format once. HEIF and JPEG XL appear only on devices where their encoders are available.
- **Save and open** saves the copy and opens it.

For a RAW file the button reads **Export** and asks for a format each time; see [RAW development](/ReFra/features/raw-development).

## Which format a copy uses

**Copy format** in the editor's settings is **Original** by default. With **Original**, a JPEG photo is saved as a JPEG at the source's own quality, and a PNG stays a lossless PNG. Pick **WebP**, **HEIF**, or **JPEG XL** to write every copy in that format instead.

A photo edited with **Remove background** is saved as a PNG so the transparent background survives.

## Where copies go

Photos are saved to `Pictures/ReFra` and videos to `Movies/ReFra`. The copy keeps the start of the original's file name with `-edited-` and a short random code added, so `IMG_2041.jpg` becomes something like `IMG_2041-edited-3f9a1c2e.jpg`. Copies show up in the timeline and in a **ReFra** album like any other media.

While a copy is written the editor shows its progress with a cancel button, and a notification tracks it too. Closing the editor before it finishes asks whether to cancel the export. When it finishes, the notification reads **Photo saved** or **Video saved**; tap it to open the copy. If saving fails, the notification says so and the editor keeps your edits so you can try again.

## When the editor was opened by another app

If another app sent the photo or video to the editor, the saved copy is handed back to that app when you close the editor. The copy is still saved in `Pictures/ReFra` or `Movies/ReFra`.

## Example: share a smaller file

1. Edit the photo as usual.
2. Open the **Save** menu and pick **Export as WebP**.
3. Open the copy from the notification and share it.
