The [editor](/ReFra/features/legacy-editor)'s toolbar keeps saving explicit: **Save Copy** writes a new file, and **More › Overwrite** replaces the original with real limits on when each is allowed.

## Save copy versus overwrite

<PreviewCollection feature="legacy-save-edits" section="save-copy-versus-overwrite" />

- **Save Copy**: writes a new file in `Pictures/Edited` and leaves the original untouched.
- **Overwrite**: offered only when the item is a local image the app can write and the format allows it. If **Overwrite** fails or Android refuses permission, choose **Save Copy**. If saving still fails, keep the editor open and resolve the permission or storage problem; do not discard your only unsaved work.
- Cloud items and read-only opens often cannot be opened in the editor at all; download the original first, or use **Save Copy** where the editor does open. Nothing silently becomes a copy.
- Closing with unsaved changes asks first: **Save Copy**, **Keep Editing**, or **Discard**.

## What a copy preserves

The copy keeps the image format when the encoder supports writing it; otherwise it falls back to PNG. Animation, layers, and HDR are not blanket guarantees; check the result's details on formats that matter to you. JPEG quality for manual saves follows **Save quality** in [viewer settings](/ReFra/features/viewer-settings).

There is no "save as JPEG" chooser for ordinary images; format selection exists only for developed RAW exports; see [RAW development](/ReFra/features/legacy-raw-development).

## Revert to original

When **Overwrite** runs, the original file is kept as an edit backup first (see [edit backups](/ReFra/features/legacy-edit-backups)). **More › Revert to original** restores it, with a confirmation since all edits are discarded. Revert exists only while that backup exists.

## Example: overwrite, then change your mind

1. Edit and **More › Overwrite** a photo; a backup of the original is created silently.
2. Later, reopen it in the editor, **More › Revert to original**, and confirm; the pre-edit file returns.
3. If the backup was already cleaned up, Revert is not offered; the edit stands.
