When you choose **Overwrite** in the [editor](/ReFra/features/legacy-editor), the original file is tucked away as an edit backup first, so **Revert to original** can undo the change later. **Settings › Smart Features › Edit Backups** manages that store.

## The backups screen

<PreviewCollection feature="legacy-edit-backups" section="the-backups-screen" />

- The header shows how much space backups use and how many exist.
- Tapping a backup opens a comparison so you can look at the **Original** versus the **Edited** result.
- **Select** marks backups for cleanup; **Delete Selected** and **Delete All Backups** confirm before running.

## Cleanup rules

<PreviewCollection feature="legacy-edit-backups" section="cleanup-rules" />

- **Auto-cleanup** is a menu action on the backups screen: running it deletes backups older than 90 days. It is something you trigger, not a schedule that runs on its own.
- Deleting a backup never deletes the edited photo; it only removes your ability to revert to the pre-edit original.
- Reverting itself happens in the editor's **More › Revert to original**, not from this screen; if a photo's backup is gone, Revert is simply not offered.

## Example: clear space after finishing a set

1. **Settings › Smart Features › Edit Backups**; check the space used.
2. Tap a backup to compare **Original** against **Edited**, and repeat for the ones you are unsure about.
3. Run **Auto-cleanup** from the menu to drop everything older than 90 days, or **Select** specific backups and **Delete Selected**; confirm. The edited photos stay; the safety net is gone.
